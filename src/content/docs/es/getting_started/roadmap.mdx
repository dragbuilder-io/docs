# Roadmap de DragBuilder

DragBuilder es una plataforma innovadora diseñada para simplificar y acelerar los procesos de creación de apps móviles. A medida que seguimos evolucionando, estamos comprometidos a mejorar nuestras funcionalidades y garantizar una experiencia sin fricciones para nuestros usuarios. A continuación, un panorama de nuestro estado actual, prioridades inmediatas y planes futuros.

---

## Estado actual

DragBuilder está **actualmente en las primeras etapas de desarrollo**. Recomendamos usar DragBuilder con **fines de evaluación** para explorar sus capacidades y brindarnos feedback valioso.

<orbit-callout intent="caution">
En esta etapa, **no se garantiza la compatibilidad hacia atrás**. Los datos de proyectos guardados en DragBuilder pueden no ser compatibles con futuras versiones.
</orbit-callout>

---

## Prioridades clave para la versión Beta

A medida que avanzamos hacia el release beta, nos estamos enfocando en varias áreas clave para asegurarnos de que DragBuilder satisfaga las necesidades de nuestros usuarios de forma efectiva. A continuación, nuestras principales prioridades:

### 1. **Integración con Firestore**

**Objetivo:**
Mejorar el manejo de datos integrando Firestore, permitiendo a los usuarios guardar y obtener datos sin fricciones.

**Funcionalidades:**

- **Almacenamiento de datos:**
  Permitir a los usuarios guardar distintos tipos de datos directamente en Firestore, garantizando persistencia de datos escalable y confiable.

- **Exposición de State:**
  Exponer los datos de Firestore como states dentro de DragBuilder, facilitando actualizaciones de UI dinámicas y reactivas basadas en cambios de datos en tiempo real.

- **Security Rules:**
  Implementar reglas de seguridad robustas para proteger los datos del usuario y garantizar patrones de acceso seguros.

### 2. **Experiencia de onboarding simplificada**

**Objetivo:**
Hacer que el proceso de onboarding sea sencillo, especialmente para usuarios nuevos en Compose, brindando herramientas y guías intuitivas.

**Funcionalidades:**

- **Plantillas de proyecto preconstruidas:**
  Empezá rápido con plantillas listas para usar, diseñadas para casos de uso comunes de apps

- **Tutorial dentro de la app:**
  Aprendé DragBuilder paso a paso a través de tutoriales guiados integrados directamente en la app

### 3. **Soporte para más Actions y configuraciones de app**

**Objetivo:**
Expandir el soporte de actions y configuraciones de app de uso común para alinearse mejor con las necesidades de aplicaciones reales

***Actions:***
  - Push notifications
  - Manejo de permisos

 ***Configuraciones de app:***
  - Personalizar íconos de app
  - Configurar Splash screens
  - Diseñar el flujo de onboarding

---

## Planes futuros

Más allá de la versión beta, DragBuilder busca introducir una amplia variedad de funcionalidades y mejoras para potenciar aún más a los creadores:

- **Asistencia de desarrollo potenciada por IA:**
  Integrar herramientas de IA para brindar sugerencias de código inteligentes, detección de errores y tips de optimización.

- **Soporte de animaciones personalizadas:**
  Habilitar la creación de animaciones personalizadas para mejorar el atractivo visual de las apps.

- **Component Library ampliada:**
  Hacer crecer continuamente la librería de componentes preconstruidos para cubrir más casos de uso y patrones de diseño.
